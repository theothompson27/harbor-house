# Harbor House Lifestyle Console

**[View Live Dashboard](https://theothompson27.github.io/harbor-house-lifestyle-console/)**

## Overview
The Harbor House Lifestyle Console is a membership amenity management dashboard designed for West Wharf. It serves as a central hub to manage programming across four floors of wellness, work, and play spaces. The console tracks event attendance against capacity, budget spend, and membership engagement metrics, while serving as the record for community newsletters.

*Note: This repository contains illustrative sample data for portfolio demonstration purposes.*

## Key Features
* **Program Management:** Schedule and track a comprehensive calendar of community events, from wellness classes to supper clubs.
* **Performance Metrics:** Calculate event fill rates, track repeat attendance (target: 30%), and evaluate overall program health.
* **Budget Oversight:** Monitor total event spend and calculate exact cost-per-head metrics.
* **Data Logging:** Input new event records—including attendance, residential turnout, and expenses—directly into the console interface.
